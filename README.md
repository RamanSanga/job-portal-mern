Job Portal - MERN Stack

A full-stack Job Portal Web Application built using the MERN Stack where companies can post job openings and job seekers can browse and apply for jobs.
This platform provides a seamless hiring experience with secure authentication, job management, and cloud-based image storage.

🚀 Features
👨‍💼 For Companies

Register and login securely

Create and post job openings

Manage job listings

View applicants for posted jobs

Update or delete job posts

Upload company logo/profile image using Cloudinary

👨‍🎓 For Job Seekers

Register and login securely

Browse all available job openings

Search and filter jobs

View detailed job descriptions

Apply for jobs directly

Manage profile information

Upload resume/profile image (if implemented)

🔐 Authentication & Security

Secure user authentication system

Login / Signup functionality

Protected routes for authorized users

Role-based access (Company / Job Seeker)

Password hashing using bcrypt

Token-based authentication using JWT

☁️ Cloud Features

Image/file upload using Cloudinary

Optimized media storage for company logos and user assets
